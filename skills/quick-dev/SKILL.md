# Quick Dev

- 此skill包含一个AGENTS需要遵守的文档和工作规范，具体文档规范为`references/documentation-lifecycle.md`，注意此规范文档应该覆盖所有其他同类型规范，包括子项目的规范如果和此规范有冲突，则以当前规范为准。
- 如果当前执行的任务很简单，则可以不按照`references/documentation-lifecycle.md`中的要求做过程文档，直接修改代码即可，此规范适用于明确要求开启的、有一定修改规模需要做计划的、需要沉淀讨论结果为解决方案的情况。
- 如果有其他skill涉及到工作流相关的规范时，你需要判断是否和当前skill规定的规范有冲突，如果有的话，需要提醒用户，并让用户选择启用哪个工作流。
