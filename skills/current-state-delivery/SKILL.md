# 当前状态交付

将当前有效的指令、提示词、记忆摘要、产品文档、代码、配置、注释、测试、模板、生成内容、交付元数据以及运行状态，视为**当前已接受状态**的表达。

当需求发生变化时，更新其权威来源以及所有直接受到影响的当前状态内容。删除那些仅因已被取代的指令而产生的过时措辞、示例、实现、校验逻辑、状态以及生成内容。

最终交付物应当只描述**当前已接受的结果**，以及仍然对该结果有实质影响的理由或约束。

不要暴露已经被放弃的替代方案、中间尝试、之前的错误，以及删除这些内容的过程；除非用户明确要求了解历史，或者这些信息对于迁移、兼容性、审计，或理解某项重要权衡仍然是必要的。
